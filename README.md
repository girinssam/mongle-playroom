# 몽글몽글 놀이방

4~6세 어린이를 위한 터치 학습 놀이 웹사이트입니다.

같은 그림 찾기, 두더지 잡기, 풍선 터뜨리기, 동물들의 주문 받기, 징검다리 건너기, 색칠하기, 그림 그리기, 퍼즐 맞추기, 장난감 전화기, 옷입히기를 제공합니다.

## 실행

`index.html`을 브라우저에서 열어 실행합니다. 그림은 HTML 안에 포함되어 있으며 별도의 빌드나 서버는 필요하지 않습니다. 웹 폰트를 불러올 때는 인터넷 연결이 필요합니다. 효과음과 한국어 음성은 브라우저 및 기기 지원에 따라 달라질 수 있습니다.

## GitHub Pages

저장소의 Settings → Pages에서 Deploy from a branch를 선택하고 `main` 브랜치의 `/ (root)` 폴더를 사용합니다.

사이트를 수정한 뒤 `index.html`의 변경 사항을 커밋하고 `main`으로 푸시하면 반영됩니다.
